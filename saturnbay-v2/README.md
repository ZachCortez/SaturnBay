# SaturnBay Official Website — v2 prototype

New Next.js App Router site, isolated under `saturnbay-v2/` to avoid overwriting the original Blazon community application while the redesign is reviewed.

## Run

```bash
cd saturnbay-v2
npm install
npm run dev
```

Open http://localhost:3000.

## Current scope

Responsive corporate landing page, four divisions (technology, motorsports, merchandise, community), Orbit / DetailFlow / Vehicle Hub product showcase, merch preview, and Blazon community teaser. Uses CSS-built graphics and Lucide icons as placeholders for approved brand imagery. Links for products not yet deployed are intentionally placeholders.

## Safety

The old Blazon code is preserved at `backup/blazon-community-original`. The current `main` branch is unchanged. This work is on `feature/saturnbay-homepage-v2` and does not yet migrate or integrate Blazon's backend.
